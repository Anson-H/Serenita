# Serenita 产品路线图

> 文档状态：路线图 / 版本范围索引
>
> 当前用途：说明当前执行版本、下一规划版本和长期草案之间的关系。具体交付范围以对应版本文档为准。

## 版本关系

Serenita 当前采用“先闭环，再扩场景，再走长期智能化”的版本路线。

| 版本 | 状态 | 核心目标 | 说明 |
| --- | --- | --- | --- |
| `v0.1.0` | 当前执行 | 注册登录、账号设置页、模型配置、首页对话、文件上下文登记、会话历史/分支、收藏 | 当前执行版本 |
| `v0.2.0` | 下一规划 | 新增报告场景 | 建立在 `v0.1.0` 稳定后，当前不直接开发 |
| `v1.0.0` | 长期草案 | 长期患者健康助手蓝图 | 范围未冻结，只作为未来方向和能力池 |

## v0.1.0 当前执行范围

必须交付：

- 基础登录、登录态保持和退出登录。
- 患者主工作台。
- 账号设置页，支持修改用户名称、修改密码、管理模型服务，以及维护默认模型用途。
- 模型服务、API key、API 地址、连接测试、模型列表获取、已添加模型，以及 `chat`、`title`、`vision_parse`、`compact` 默认模型用途配置；`vision_parse` 在 `chat` 模型不能原生处理附件时用于直接完成带附件回答，`compact` 在 v0.1.0 只做设置入口和数据库预留。
- 首页基础文本对话、推理强度、会话持久化、流式输出和生成中取消。
- 图片、OpenRouter 和阿里云百炼支持模型的音频/视频、provider adapter 原生支持的 PDF 作为首页对话上下文资源登记，并按模型能力和 provider 原生附件能力校验是否允许上传或发送；Office 文档仍不开放，除非 provider adapter 后续实现原生文件输入。
- 会话历史保存、恢复、编辑提问、重新生成和分支切换。
- AI 回答收藏、收藏列表、收藏详情、标签编辑和取消收藏。
- 当前用户数据隔离。

当前代码说明：

- 对话服务会在流式接口被订阅时调用已配置模型服务生成回答，已完成会话、上下文、分支和收藏链路的持久化。
- 首页上传文件会保存并按 `chat` 模型、`vision_parse` 模型和 provider adapter 能力校验。发送时，`chat` 模型原生支持的附件直接转发给 `chat` 模型；`chat` 模型不支持但 `vision_parse` 支持的附件直接转发给 `vision_parse`，由视觉解析模型生成本轮回答；两者都不支持时拒绝上传或发送。
- 报告、生活和原始文件入口仅做占位；报告占位接口返回空列表。

可占位：

- 报告场景。
- 生活场景。
- 原始文件入口。

明确不做：

- 报告场景真实发送、正式报告上传和结构化解析入库。
- 报告分析。
- 生活场景真实发送和正式生活管理。
- HealthKit 或可穿戴设备接入。
- 多 Agent 综合评估。
- 医生端或管理后台。
- 导出、分享、支付、处方。

## v0.2.0 下一版本范围

以下内容只作为下一规划；进入开发前必须重新确认，并且不得覆盖当前执行版本的约束：

- 报告上传入口。
- 报告文件保存。
- 报告结构化解析和入库。
- 报告列表、筛选、排序。
- 单份报告详情。
- 报告分析确认机制。
- 报告分析结果展示和写回。
- 报告类收藏。

## v1.0.0 长期方向

长期可以探索：

- 日常生活管理。
- 健康卡片和趋势。
- 多 Agent 编排。
- 更完整的报告视觉解析 / 多模态解析。
- HealthKit 或设备数据。
- 长期患者档案。
- 风险识别和主动提醒。
- 医疗安全、审计、合规体系。

这些能力目前都不自动进入开发，必须拆分到后续版本 PRD 后再执行。
