# Serenita 未来愿景

> 文档状态：未来愿景 / 不绑定版本
>
> 负责：记录尚未纳入当前执行的产品方向、探索问题和进入开发的前提。
>
> 当前依据：[当前执行文档](../当前执行/README.md)。

Serenita 的长期方向是帮助用户持续整理、理解和使用自己的健康信息，并在授权的持续关注范围内主动发现问题、推荐行动和跟踪结果。未来能力沿用通用 Agent Harness，由模型根据用户目标、Skill 正文和 Observation 自主行动。

本目录只维护仍有讨论价值的未来设想。已经进入当前执行的能力回到对应契约；已被替代的接口、数据库草案、运行命令和演示流程直接删除。

## 当前基础与未来增量

当前 v0.2.0 已将医疗报告管理、报告解读、动态工具调用、公网研究、多成员与健康档案授权纳入执行范围。具体能力和验收见[产品需求](../当前执行/产品/产品需求.md)，不由本目录重新定义。

| 当前基础 | 未来增量 |
| --- | --- |
| 成员资料、既往史、健康日记、用药记录、身体指标与站内提醒 | 手机自动同步、厂商原生格式与跨领域趋势 |
| 医疗报告导入、查询、比较与修正 | 可追溯的指标趋势视图、跨资料整理和就医摘要 |
| 医疗资料、会话、附件和可验证的行动结果 | 只追加的 Memory Graph、完整保留演化记录的连续认识、主动推荐及持续任务 |
| 通用 Agent Harness | 经评估确有收益的多智能体协作与资源管理能力 |
| 当前工作台和窄屏交互 | 健康概览、设备数据展示、语音和移动端体验 |

表中的当前基础表示当前契约范围，不是本次审查出具的全量功能验收结论。

## 使用规则

- 本目录不承诺版本、排期或交付，不作为当前开发和验收依据。
- 新方向先明确用户目标、范围、授权、失败处理和验收方式，再迁入当前执行的对应专题。
- 术语和身份遵循[当前术语表](../当前执行/术语表.md)及[成员与健康档案授权](../当前执行/领域/成员与健康档案授权.md)。
- 长期记忆的项目概念统一使用[固定术语](长期记忆与认知架构.md#固定术语)，全部对象、关系、状态及持久派生内容遵循[Append-only 规则](长期记忆与认知架构.md#append-only全部记忆只允许追加)。
- 未来设想同样遵守[项目开发规则](../../AGENTS.md)，不引入替模型决定业务步骤的固定工作流。
- 技术选项需说明适用条件；性能和质量结论需有可追溯测量，未测量时不标记为已达标。
