# Serenita 未来愿景：前端

> 文档状态：未来愿景 / 不绑定版本
>
> 负责：未来健康资料与持续任务的交互方向。
>
> 当前依据：[前端行为与交互](../当前执行/前端/行为与交互.md)、[视觉契约](../../DESIGN.md)。

## 健康档案的连续阅读

沿用当前成员与健康档案工作台，探索身体指标、医疗日志和用药记录的列表、详情与编辑体验。各类资料展示明确的成员归属、记录时间和来源，避免用户在家属资料之间混淆。

健康概览可以按用户关注点组织近期信息，允许追溯到具体记录。概览卡片不必覆盖每种资料，也不固定要求所有回答使用卡片。

## 趋势与证据

指标趋势可提供时间范围选择、原始记录定位和并列查看。图中表达单位、参考范围变化、缺测及不可比数据，避免仅用颜色传达异常。

跨资料时间线可以把报告、用户记录和设备测量放在同一时间轴，但保留来源差异。用户应能从摘要进入原件或记录详情。

## 智能体行动与结果

未来能力复用当前会话和真实执行记录。界面根据真实任务状态展示等待、执行、失败和完成，不预设业务阶段或模拟百分比。

从健康资料发起任务时，应保持目标资料可识别，并提供返回结果和来源的路径。布局与导航由具体体验决定，不强制所有任务跳转到同一首页。

报告界面动作继续使用“开始解读”和“重新解读”。其它资料类型进入开发时再定义与其任务一致的文案。

## 主动提醒与长期记忆

提醒管理可以展示任务目标、成员、资料范围、运行时间和通知方式，并提供暂停、修改、取消及执行记录。

长期记忆可以提供查看依据、纠正内容和删除的入口。是否保存、何时更新及共享给谁应当可理解；缺少授权时不能用界面默认状态暗示已经获得同意。

## 设备与移动体验

设备接入应表达真实连接状态、最近同步时间和数据缺口。授权取消或同步失败后，已有数据的保留和展示按确定的产品规则处理。

语音采集、转写校对和移动端上传可独立探索。只有具备实际能力时才展示可操作入口，权限和错误反馈也应可理解。

所有新视图延续键盘可操作、窄屏可读、焦点清晰和状态不只依赖颜色的要求。具体控件与布局在功能范围确定后进入当前前端契约。
