# 当前术语表

> 文档层级：当前执行 / 术语契约
>
> 负责：跨产品、架构、领域、接口和前端文档共用术语的唯一含义。
>
> 不负责：业务流程、字段结构、HTTP 路由或页面行为。
>
> 使用规则：正文优先使用本表中文术语；代码标识、事件类型和接口字段保持代码原名。

## 身份与资料

| 术语 | 含义 | 相邻概念 |
| --- | --- | --- |
| 账号 | 登录、操作和账号级配置的主体，由服务端生成的规范 UUID `account_id` 标识 | 医疗资料所属的人由成员表示 |
| 用户标识 | `account` 字段承载的登录标识，可修改、大小写不敏感且全局唯一，也用于界面标识和授权接收方查找 | 内部归属与目录使用 `account_id` |
| 账号名称 | `account_name` 字段承载、便于人识别的账号界面称呼，可修改；去除首尾空白后为 1–50 个 Unicode 码点，并允许内部空格 | 登录使用用户标识；成员名称由 `member_name` 保存 |
| 成员 | 一名医疗资料所属人的领域对象，由不可变 `member_id` 标识；字段和接口中的 `member_id` 统一表述为“成员 ID”或“所属成员” | 操作主体由账号表示 |
| 健康档案 | 一名成员的基础资料、医疗报告、解读结果及来源共同构成的数据范围；不设独立“档案 ID”，数据通过 `member_id` 关联所属成员；前端同名工作区用于浏览这些内容 | 成员身份或账号 |
| 健康档案所有者账号 | 创建成员并保存该成员医疗资料、管理健康档案授权的账号，由 `account_id` 标识 | 医疗资料所属的成员或当前操作账号 |
| 默认成员 | 操作账号启动时可以选择的唯一成员偏好目标 | “本人”身份、所有权或更高权限 |
| 报告档案库 | 一名成员名下正式保存医疗报告、解读结果与来源关联的领域集合 | 聊天附件目录或候选状态机 |

## 会话与执行

| 术语 | 含义 | 相邻概念 |
| --- | --- | --- |
| 会话 | 操作账号拥有的一段聊天，创建后固定绑定一名成员或永久不关联成员 | 可以随界面选择改绑的容器 |
| 当前轮次 | 当前用户输入触发的一次 Agent 执行，从输入提升到终态 | 整个会话或规划阶段 |
| 会话事件日志 | 会话事实的只追加事件序列及其 header，是详情、模型上下文和 SSE 的共同可信源；每个会话对应一个 JSONL | `conversations.db` 中的会话索引或用户可见页面本身 |
| 执行记录 | 前端从会话事件投影出的上下文、模型、工具和错误记录 | 另一套持久化日志 |
| 工具调用 | 模型请求执行一个工具及其参数 | 技能激活或业务阶段 |
| 工具结果 | 工具执行后持久化的结构化成功或失败结果 | 模型对结果的解释 |
| 工具观测 | 回到行动循环、供模型读取并决定下一步的工具执行信息 | 后端替模型决定的下一步 |
| 技能 | 模型按需读取的领域规程正文 | 可自行执行的工作流或状态机 |

## 报告与证据

| 术语 | 含义 | 相邻概念 |
| --- | --- | --- |
| 医疗报告 | 报告档案库中的正式结构化报告对象 | 尚未写入的解析候选 |
| 报告事实 | 医疗报告的基础信息和结构化内容 | 解读结果 |
| 报告解读 | 读取原始证据、生成或更新解读结果的任务、能力或过程 | 一个字段名 |
| 解读结果 | 报告解读生成或更新的正文、状态、更新时间和过期状态 | 报告事实或来源原文 |
| 来源 | 与医疗报告关联、可追溯的原件 | 来源元数据、来源原文或医学结论 |
| 来源元数据 | 来源的身份、类型、顺序与关联状态 | 实际原件内容 |
| 来源原文 | 实际读取的原件内容 | 从解读结果反推的内容 |
| 原始证据 | 当前医学判断实际使用的来源原文 | 既有解读结果 |
| 完整解析校验结果 | `validate_parsed_reports` 对一批最终医疗报告返回的校验结果 | 候选、待审或冲突业务实体 |
| 检验指标分类目录 | 健康档案所有者账号维护并在其自有成员间共用的指标、别名与分类口径 | 操作账号查看共享健康档案时自己的目录 |

## 联网

| 术语 | 含义 |
| --- | --- |
| 搜索结果 | `web_search` 返回的一条公开互联网结果 |
| 搜索结果摘要 | 搜索供应商随搜索结果返回的摘要，不能单独支撑关键医学结论 |
| 网页正文 | `web_read` 对既有搜索结果读取的实际页面内容 |
