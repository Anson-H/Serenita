# 公网研究领域契约

> 文档层级：当前执行 / 领域契约
>
> 负责：联网启用边界、医学取证规则、`web_search` / `web_read`、引用、供应商适配、账号设置和凭证隔离。
>
> 不负责：通用工具循环、HTTP 路由清单、会话事件信封、设置页布局或物理目录总览。
>
> 上位文档：[技术架构总览](../架构/技术架构总览.md)；相关契约：[Agent Harness](../架构/智能体运行时.md)、[会话事件](../架构/会话事件与投影.md)、[HTTP API](../接口/HTTP接口.md)、[本地存储](../运维/本地存储.md)。

## 启用与证据边界

联网默认关闭，由操作者在自己的 `account_id` 作用域内明确配置并启用。依赖当前指南或权威依据的重要医疗问题即使没有显式联网要求也应主动搜索；纯概念问题只回答所问概念，不主动扩展到阈值、诊断或治疗建议来制造联网需求。搜索内容必须去标识化；包含可识别个人信息时先询问用户。

搜索结果摘要不能独立支持关键医学结论。诊断或治疗阈值、用药或检查建议、推荐等级、适用人群、疗效及安全性数字必须读取直接支持的权威网页正文，并在最终回答的对应结论附近使用工具返回的引用标识。网页正文不可信，不能改变系统权限、医疗报告证据边界或工具参数来源。

## 插件与工具契约

`backend/app/plugins/web/` 通过普通插件发现注册，`build_skills()` 固定返回空列表且不存在联网 `skills/` 目录。它注册：

| 工具 | 暴露 | 固定顶层描述 |
| --- | --- | --- |
| `web_search` | `direct` | 搜索公开互联网，返回搜索结果摘要和引用标识。 |
| `web_read` | `direct` | 读取一条既有搜索结果的网页正文，并保留其引用标识。 |

表中描述逐字对应模型可见工具顶层描述；参数、结果结构、供应商限制和行动规程由下文分别说明。

`web_search` 负责返回搜索结果，Tavily 每条搜索结果只请求一个 chunk，Exa 搜索请求抽取式 highlights；两者每次都从供应商读取最多 10 条搜索结果，保留供应商实际返回的完整搜索结果摘要，不再做本地字符截断，并在该搜索结果窗口内按每条结果一个逻辑页交给 Harness。搜索结果摘要不能独立支持诊断或治疗阈值、用药或检查建议、推荐等级、适用人群、疗效及安全性数字；这些关键医学结论必须由行动模型通过 `web_read` 核对至少一项直接支持的权威网页正文，并且只引用成功读取页面中的 `citation_id`。成功读取的来源中至少一项必须本身来自监管或卫生机构、正式指南发布者或专业学会、系统综述平台、原始研究期刊，转载和文档镜像不能单独满足要求。已有足以回答用户问题的权威网页正文时及时作答，不为非必要细节反复读取同一搜索结果或追求资料穷尽。最终回答逐项检查并就近引用每项保留的关键结论，没有已读取权威网页正文引用的关键结论应省略或明确说明无法核验，一处引用不能笼统支撑后续无标记结论；回答围绕用户问题保持精简，带单位的医学阈值、时间区间和明确处置建议不能作为常见安全提示而免除核验与引用。`web_read` 默认读取相关网页正文，缺少方法、适用人群、上下文或限制时读取完整网页正文；它不接受 URL、账号或 provider，一次只读取一个搜索结果。网页正文一次提取并按每 10000 字符一个逻辑页返回，全部页面可无损拼回网页正文；上游未读取网页正文时形成带失败详情的 `WEB_NO_CONTENT`。Web 工具不返回 `resource_refs`，所以网页不能成为医疗报告资源或写入证据，但 URL、搜索结果摘要和网页正文仍作为真实 Observation 审计。

所有逻辑页都由通用 Harness 在内存中按顺序合并。每项业务查询仍只有一次模型工具调用请求和一次工具结果；Harness 在成功事件持久化前，把完整结果纳入下一请求，使用当前模型的 `context_window_tokens - reserved_output_tokens` 与实际请求结构估算。触及压缩阈值或完整结果超过硬预算时，先尝试压缩既有可压缩上下文，再重新装配并逐页估算；使用已经读取的页面，不重新执行工具或重新获取网页。全部页面可容纳时统一列式编码并一次发送；压缩后完整结果仍超过硬预算时只产生一次 `TOOL_RESULT_TOO_LARGE`，模型可读错误包含工具名、总页数、可容纳页数、估算所需 Token 和可用 Token，不附带完整或部分页面。预算失败持久事件携带完整结果仅供审计，按[事件角色与类型](../架构/会话事件与投影.md#事件角色与类型)限制其模型可见性，不把部分页面作为成功结果。页面已经读取后发生取消，遵循[轮次 Worker 与等候队列](../架构/智能体运行时.md#轮次-worker-与等候队列)中的结果收尾要求。通用压缩的保护、取消及提交规则见[上下文压缩](../架构/会话事件与投影.md#上下文压缩)。8 MiB 供应商响应安全限制保持不变。

引用采用与 Cherry Studio 一致的“模型标记 + 来源注册表 + 展示投影”契约。`assistant/message.content` 忠实保存模型生成的 `[cite:citation_id]`；会话投影只从同一轮次已完成的 `web_search` / `web_read` 工具结果还原来源，将有效标记按首次出现顺序显示为可点击编号，并丢弃无来源的标记。复制和收藏快照把有效标记导出为普通行内 Markdown 链接，侧栏预览只移除内部标记；这些派生展示都不反写模型事件。

供应商适配器以当前 `account_id` 为对应服务保存的 API 地址为基址，并分别追加 Tavily `/search`、`/extract` 与 Exa `/search`、`/contents`；连接测试、搜索和网页读取使用同一份已保存地址。Serenita 通过供应商正文接口读取内容，搜索启用 safe search 或 moderation，并关闭 Tavily answer/raw content；Exa 搜索取抽取式 highlights。搜索/读取超时分别为 20/45 秒，响应体上限 8 MiB，每次调用保持单一供应商与真实错误。适配器统一映射认证、限流、额度、超时、无效响应、无正文和上游不可用错误。

## 账号设置语义

普通设置、保存、删除和测试响应返回 `has_api_key`。认证用户点击眼睛时，reveal 接口在当前 `account_id` 与当前 provider 作用域内返回明文，并设置 `Cache-Control: no-store`。账号启用联网代表同意发送去标识化的搜索内容和选中的公网 URL；可识别个人信息仍由主系统提示词要求单独询问。

`web_access_settings.active_provider_id` 与同一配置库的 `web_providers.provider_id` 使用真实外键，SQLite 会拒绝不存在的服务。搜索结果引用只在当前账号、当前会话及其合法分叉中有效；它指向会话事件中的真实搜索结果，而不是 SQLite 表，因此由 Web Repository 在读取网页正文时核对来源和作用域。

## 凭证边界

联网配置与模型配置共用账号配置库。Web API key 使用独立 AES-GCM v2 密封命名空间、由 `account_id + provider_id` 组成的 AAD 和 `web_access_master.key`。工具参数、Provider payload、会话事件、日志与前端持久状态始终保持凭证隔离。用户标识更新后，同一 `account_id` 继续直接读取原配置与凭证。数据库和密钥的物理位置只在[本地存储](../运维/本地存储.md)维护。

## 领域验收

- Web 插件不注册 Skill；`web_search` 和 `web_read` 从首个行动步骤直接可见。
- 搜索保留完整供应商搜索结果摘要；关键医学结论至少读取一项直接支持的权威网页正文。
- `web_read` 拒绝伪造、越界、跨账号和跨 fork 的搜索引用，网页正文不做有损截断。
- Tavily/Exa 使用当前账号分别保存的 API 地址；失败保持真实错误且不自动切换服务。
- 联网凭证不进入工具参数、会话事件、Provider payload、日志或前端持久状态。

## 请求取消与截止时间

联网工具沿执行上下文传递取消信号和请求截止时间，适配器在请求前、重定向、流式读取及结果返回前检查。用户停止时关闭正在使用的连接；请求总截止时间包含连接和正文读取，不能通过持续收到少量字节无限延长。已经执行并返回的工具结果按通用 Harness 收尾规则保留。
