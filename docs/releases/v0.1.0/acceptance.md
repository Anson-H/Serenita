# Serenita v0.1.0 验收清单

> 文档状态：当前执行 / 当前执行版本的验收标准
>
> 对应产品需求文档：[账号注册与登录](./prd/auth.md)、[账号设置](./prd/account-settings.md)、[首页对话](./prd/home-conversation.md)、[收藏](./prd/favorites.md)

本清单用于确认 v0.1.0 的最小可用闭环是否完成：用户能安全进入自己的工作台，完成账号设置和模型配置，在首页完成一次可恢复的 AI 问答，并把有价值的回答沉淀到收藏中。报告、生活和原始文件入口只验收占位边界，不验收正式业务能力。

## 1. 注册与登录

- 未登录用户打开产品或访问受保护页面时只能看到登录页 `/sign_in`。
- 登录页 `/sign_in` 包含账号、密码、登录按钮、注册入口、错误提示和加载状态。
- 密码输入支持显示/隐藏切换，切换不改变输入值。
- 新用户可通过注册入口进入注册页 `/sign_up` 创建账号。
- 注册页 `/sign_up` 表单包含账号、用户名称、密码、确认密码、注册规则提示、注册按钮、错误提示和加载状态。
- 注册表单中的密码和确认密码输入支持显示/隐藏切换，切换不改变输入值。
- 注册时账号重复、必填项为空、密码为空或两次密码不一致时展示错误提示；登录时账号或密码为空也展示错误提示。
- 注册或登录时，账号包含英文字母、数字、下划线和短横线之外的字符，或长度超过 20 个字符时展示明确错误提示。
- 密码不限制长度，不做复杂度校验；非空且两次输入一致即可通过密码规则。
- 非法账号不得创建账号记录或账号私有目录。
- 注册成功后可进入患者主工作台 `/`，或回到登录页 `/sign_in` 并提示注册成功。
- 登录成功后进入患者主工作台 `/`。
- 登录成功后能获得当前 `account`。
- 刷新页面后，在会话有效期内能恢复登录态。
- 刷新页面恢复登录态时，服务端能仅凭 `session_token` 定位当前账号，不要求前端先传入 `account`。
- 点击退出登录后清除当前登录态并返回登录页 `/sign_in`。
- 退出后不得继续展示上一位用户的会话或收藏。

## 2. 账号设置与模型配置

- 用户可从左下角账号按钮直接进入账号设置页 `/setting`。
- 账号设置页保留左侧主工作栏，切换页面后仍保持当前登录态和用户摘要。
- 账号设置页内部导航包含 `账号资料`、`密码安全`、`模型提供方` 和 `默认模型`。`退出登录` 位于同一设置页一级导航中。
- 默认模型设置页支持分别维护 `chat`、`title`、`vision_parse` 和 `compact`。
- `账号资料` 展示当前 `account` 和 `user_name`。
- 当前 `account` 不可修改，不提供可编辑输入框。
- 用户可修改 `user_name`；输入短暂停顿后自动保存，保存成功后全局侧边栏用户摘要和会话恢复信息同步更新。
- `user_name` 为空或包含空格时展示错误提示，不保存。
- 用户可通过当前密码、新密码和确认新密码修改密码。
- 修改密码表单的三个密码输入支持显示/隐藏切换，切换不改变输入值。
- 当前密码错误、新密码为空或两次输入不一致时展示明确错误提示，不修改密码。
- 密码修改成功后展示成功反馈，清空当前密码、新密码和确认新密码输入框，并使其它已登录会话失效。
- 用户可选择模型提供方，当前支持 OpenRouter、深度求索、阿里云百炼。
- 模型提供方列表展示服务名称、连接测试图标状态和进入详情箭头，且不展示 API 地址。
- 模型提供方配置加载失败时在服务列表展示错误消息；当前页面不提供独立的全页加载中占位。
- 用户选择模型提供方后，系统自动填入官网地址和 API 地址，用户可输入自己的 API key。
- 用户可修改官网地址和 API 地址。
- 官网地址、API 地址和 API key 输入后自动保存；不展示单独的保存配置按钮。
- 已保存 API key 回填到输入框，用户可直接编辑后自动覆盖保存。
- API key 输入支持显示/隐藏切换，切换不把 API key 写入前端持久化存储。
- 用户可使用当前表单 API 地址和 API key 测试连接；测试成功、认证失败、超时或服务错误均有明确反馈。
- 模型提供方详情中的模型列表展示已添加模型；用户点击 `添加模型` 后打开弹窗，系统基于已保存 API 地址和 API key 获取该模型服务远端模型列表，列表按厂商返回顺序展示，用户可添加需要使用的模型；远端模型列表加载失败时展示错误原因和重试入口。
- 添加模型时保存拆分后的能力字段；远端没有能力元数据时使用模型服务适配器、内置规则或保守默认能力。
- 添加第一个模型且当前账号尚未设置 `chat` 默认模型时，前端会自动把新增模型设置为 `chat` 默认模型；已有 `chat` 默认模型时，新增模型不自动切换默认用途。
- 用户可删除已添加模型；删除被默认用途引用的模型后，系统清空对应默认用途或要求用户重新选择，不保留悬空引用。
- 用户可在 `默认模型` 中分别设置 `chat`、`title`、`vision_parse` 和 `compact` 四个用途；`vision_parse` 用于 `chat` 模型不能原生处理附件时直接完成带附件回答，`compact` 在 v0.1.0 只验收设置入口和数据库预留。
- `vision_parse` 候选列表只展示 `file_mime_types` 中包含图片 MIME 的视觉模型。
- `chat` 用途用于首页真实发送的后端最终校验；首页模型弹层会刷新全部已添加模型并将 `chat` 默认模型置顶，前端附件按钮同时参考当前 `chat` 模型和 `vision_parse` 模型的文件能力，后端上传和发送仍只接受 `chat` 默认模型作为请求模型。
- `title` 用途用于会话标题生成；未设置时回退 `chat`，模型调用失败时回退本地标题规则。
- API key、已添加模型和默认模型设置必须绑定当前 `account`；不同 `account` 不能共享或看到彼此的 API key 和模型配置。
- 推理强度/模型浮层展示当前可选模型和对应推理强度；`chat` 默认模型应置顶。
- 推理强度菜单只展示当前模型能力支持的档位，不支持的档位不可选择。
- 当模型能力包含 `xhigh` 时，前端可展示“超高”档位；不包含时不得展示。
- 前端提交不受当前模型支持的推理强度时，后端拒绝请求且不调用模型服务。
- 未配置模型服务、未添加可用模型或未设置可用 `chat` 默认模型时，发送消息展示模型配置引导。

## 3. 首页对话

- 用户可在首页输入文本问题，也可在已有附件或历史引用等上下文资源时发送无文本消息。
- 没有文本且没有上下文资源时不能触发发送。
- 发送后展示加载状态并阻止重复提交。
- 用户可复制任一历史用户消息或助手消息的文本内容。
- 对话输出支持通过流式接口展示；当前实现会在订阅流式接口时调用已配置模型服务，已完成、取消或失败的轮次再通过同一接口回放终态事件。
- 流式连接中断或页面关闭时，应可通过轮次状态接口或会话详情恢复已完成内容、已取消内容或生成中状态。
- 后端写入完成后，首页展示助手回答。
- 用户可在首页对话中附加图片、provider adapter 原生支持的 PDF、OpenRouter 或阿里云百炼对应模型原生支持的音频/视频作为上下文资源；Office 文档不作为 v0.1.0 可上传附件，除非 provider adapter 后续实现原生文件输入。
- 单文件超过 20MB 时展示文件大小超限错误。
- 文件类型不在白名单中时展示文件类型不支持错误。
- 显式校验失败的文件上传不写入会话时间线，也不写入资源索引；文件落盘或数据库异常的统一 `UPLOAD_FAILED` 包装和残留清理属于后续补强边界。
- 当前 `chat` 模型和 `vision_parse` 模型都不支持所附文件格式时展示模型文件能力不支持错误，且不写入 `file_upload` 或 `user_message`。
- 文件上传成功但未发送时，该资源不写入会话时间线；资源过期或被清理后不能再被发送引用。
- 文件上传成功但未发送时，草稿会话可通过会话详情接口读取且消息列表为空，但不得出现在左侧最近会话列表；发送第一条用户消息后才进入最近会话列表。
- 当前实现验收文件上传、登记、过期、模型能力校验、provider 原生附件能力校验、视觉解析回退和引用写入。发送时，若 `chat` 模型原生支持附件 MIME，后端直接转发给 `chat` 模型；若 `chat` 模型不支持但 `vision_parse` 模型支持，后端直接调用视觉解析模型并把附件作为原生输入发送，由 `vision_parse` 生成本轮回答；两者都不支持时拒绝上传或发送。
- 首页文件上下文只进入会话时间线和本轮 AI 上下文，不触发报告结构化字段抽取、指标入库或报告列表刷新。
- AI 回答至少包含核心结论和下一步建议。
- 风险相关回答优先展示风险等级或需要关注的信号。
- 请求失败时展示错误提示，并允许用户重新发送。
- 若同一会话存在生成中轮次，用户不能继续发送或重新生成；用户可先停止当前生成，停止后可继续发送或重新生成。
- 普通停止生成会保留已展示的半截 AI 回答，并在历史中标记为已取消；生成中点击重新生成会丢弃当前半截回答并开始新一轮生成。

## 4. 会话历史

- 每轮用户消息和 AI 回答都绑定当前 `account`。
- 每轮消息都绑定 `session_id` 或等价会话标识。
- 左侧展示最近会话列表。
- 点击历史会话能恢复对应消息。
- 访问 `/chat/{session_id}` 能打开指定历史会话，并保持与 `/` 相同的患者工作台外壳。
- 快速切换历史会话或开启新对话时，旧会话详情响应不得覆盖当前页面状态。
- 打开或切换历史会话时，历史滚动位置应先清空，再定位到当前会话最新消息；自动滚动应锚定最新消息本身，而不是底部输入框留白。
- 刷新页面后能恢复最近会话。
- 编辑历史用户提问或重新生成 AI 回答时，系统保留原消息链并形成分支。
- 存在分支时，消息下方展示分支切换控件（“当前序号/总数” + 左右箭头），可切换查看不同分支。
- 存在思考过程节点时，分支控件按用户可见的问题和回答路径计数，不把思考节点单独计为可切换分支。
- 切换分支时，后端校验提交的活动路径属于当前 `account` 和当前会话，且消息链路连续。
- 用户可从历史消息中选中文字作为本轮上下文引用，刷新后仍能看到该引用关系。
- 历史消息引用必须由后端校验当前 `account`、当前会话和引用文本来源，不能只信任前端提交的 `message_id` 或选中文本。
- 用户可删除当前会话；删除后最近会话列表刷新，当前对话、待上传资源、历史引用和分支起点状态清空。
- 删除会话会删除该会话索引、时间线文件、轮次记录、资源索引和附件目录。
- 删除会话不删除已有收藏快照。
- 不同 `account` 之间不能互相看到会话。

## 5. 收藏

- 每条 AI 回答都有收藏入口。
- 未收藏状态点击后创建收藏快照。
- 收藏成功后原回答展示已收藏状态。
- 收藏失败时展示明确反馈，且不影响原回答展示。
- 用户可进入我的收藏页 `/favorites` 查看收藏列表。
- 收藏列表项包含标题、来源类型、创建时间和内容摘要。
- 收藏列表项在摘要下方展示来源类型、创建时间和标签；标签以胶囊形式展示，可在列表内直接新增或移除。
- 点击收藏项可查看收藏详情。
- 收藏详情展示收藏时的内容快照。
- 收藏详情标题下方展示来源类型、创建时间和标签；标签编辑使用胶囊控件，结束编辑或点击外部时自动保存，不展示单独的“保存标签”按钮。
- 原会话仍存在时，收藏详情可通过 `/chat/{source_session_id}` 返回原对话并定位到来源消息。
- 原会话已删除时，收藏详情仍展示快照，不展示返回原对话入口。
- 用户可在原回答上取消收藏；收藏页通过批量选择模式删除选中收藏。
- 用户可编辑收藏标签。
- 用户可显式进入批量选择模式；进入批量模式不会自动选中全部收藏，可手动全选、取消全选、批量设置标签或删除选中收藏。
- 取消收藏不删除原始对话。
- 不同 `account` 之间不能互相看到收藏。

## 6. 占位入口

- 报告场景可显示占位状态，不交付正式报告能力，也不允许发起真实大模型请求。
- `GET /api/reports` 可作为报告占位接口返回空列表；当前实现不校验登录态、不读取账号数据，不得被前端表现为正式报告能力。
- 生活场景可显示占位状态，不交付正式生活管理能力，也不允许发起真实大模型请求。
- 报告和生活场景当前通过占位标题和输入框 placeholder 表达未开放，文本输入禁用，附件按钮隐藏，提交动作不调用后端。
- 原始文件入口可显示占位状态，不录入正式文件或报告结构化数据。
- 所有占位入口不得误导用户以为能力已经完成；首页文件上下文上传也不得暗示报告能力已经完成。

## 7. 数据隔离与安全

- 登录、账号设置、模型配置、上下文资源、对话和收藏数据绑定当前 `account`。
- 后端校验当前会话与 `account` 的关系。
- 前端不得仅依赖本地 `account` 判断权限。
- API key 不得写入前端本地持久化存储；模型服务配置接口可明文返回当前账号已保存的 API key 以支持编辑。
- 文件资源引用必须由后端校验当前 `account` 和当前会话归属，前端传入的路径、哈希、MIME 类型和大小不作为可信来源。
- 错误响应包含可读的错误信息。

## 8. 明确不验收

以下内容不属于 `v0.1.0` 验收范围：

- 报告场景上传入库。
- 报告结构化字段抽取、OCR 入库或多模态报告入库解析。
- 报告列表、报告详情、报告分析。
- 报告/生活场景真实发送和分屏对话模式。
- 长会话自动压缩和 token 级上下文历史裁剪。
- HealthKit 或设备数据。
- 生活建议正式能力。
- 多 Agent 编排。
- 医生端。
- 管理后台。
- 导出、分享、支付、处方。
