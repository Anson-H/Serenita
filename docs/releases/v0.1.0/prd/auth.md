> 文档状态：当前执行 / 当前执行版本
>
> 所属索引：[v0.1.0 产品需求文档索引](./README.md)
>
> 对应技术设计：[账号注册与登录技术设计](../technical/auth.md)

## 1. 目标

注册与登录模块负责让患者安全进入自己的工作台，并在刷新页面、退出登录和跨账号切换时保持清晰的数据边界。

本模块交付：

- 登录页 `/sign_in`
- 注册页 `/sign_up` 与注册表单
- 登录态保持与恢复
- 退出登录
- 密码输入显示/隐藏控件

本模块不交付：

- 找回密码
- 验证码
- 多角色权限
- 账号管理后台

## 2. 页面与状态

登录页在未登录时展示，访问路径为 `/sign_in`。注册页访问路径为 `/sign_up`。已登录用户访问 `/sign_in` 或 `/sign_up` 时，系统应进入患者主工作台的首页工作区。

登录页至少包含：

- 品牌与产品定位
- 登录/注册切换入口
- 账号输入框
- 密码输入框
- 登录按钮
- 注册入口
- 错误提示
- 加载状态

注册表单至少包含：

- 账号输入框
- 用户名称输入框
- 密码输入框
- 确认密码输入框
- 注册按钮
- 注册规则提示
- 错误提示
- 加载状态

密码与确认密码输入框应支持显示/隐藏切换。切换只改变当前输入框的可见性，不改变密码值，不把密码写入日志或非必要状态。

## 3. 用户流程

1. 用户打开产品。
2. 系统检查本地登录态。
3. 若存在有效登录态，直接进入患者主工作台的首页工作区。
4. 若无有效登录态，展示登录页 `/sign_in`。
5. 已有账号用户输入账号和密码并提交登录。
6. 新用户切换到注册页 `/sign_up`，输入账号、用户名称、密码和确认密码并提交。
7. 注册成功后，系统在共用登录凭证库中创建该 `account` 的记录，并初始化账号私有数据目录。
8. 注册成功后可直接建立登录态并进入患者主工作台的首页工作区；若不自动登录，也必须回到登录页 `/sign_in` 并给出注册成功提示。
9. 登录成功后，系统保存 `account`、`user_name` 和登录会话令牌 `session_token`。
10. 服务端需能仅凭 `session_token` 恢复当前账号，不得要求前端在恢复登录态前先提供 `account`。
11. 用户点击退出登录后，系统清除当前登录态并返回登录页 `/sign_in`。

## 4. 功能需求

### FR-AUTH-001 注册

- 注册时账号不能为空且不可与已有账号重复。
- 账号必须仅由英文字母、数字、下划线和短横线组成，长度为 1-20 个字符。
- 账号匹配建议不区分大小写，账号目录名使用规范化后的账号。
- 注册时用户名称不能为空，且不能包含空白字符。
- 密码不能为空，不设置长度限制，不做复杂度要求。
- 确认密码必须与密码完全一致。
- 注册成功后必须在 `all_users/auth/auth_info.db` 中创建当前 `account` 的登录凭证。
- 注册成功后必须初始化 `{account}/` 账号私有数据目录。
- 非法账号不得创建账号记录或账号私有目录。
- 密码不得明文保存。

### FR-AUTH-002 登录

- 登录时账号和密码均不能为空。
- 登录时账号同样按注册规则校验。
- 登录成功后必须获得 `account`、`user_name`、`session_token` 和可选 `expires_at`。
- 登录成功后进入患者主工作台的首页工作区。
- 登录失败时展示明确错误提示，不进入首页。

### FR-AUTH-003 登录态保持

- 系统应支持登录态保持；刷新页面后，在会话有效期内自动恢复登录。
- `session_token` 可通过同源 HttpOnly Cookie 或 `Authorization: Bearer` 头传递。
- 服务端保存 `session_token` 的不可逆哈希，不保存明文 token。
- `GET /api/auth/session` 必须只依赖 Cookie 或 Authorization 头中的 token 定位当前账号。
- `session_token` 有效期为 6 个月；过期后需重新登录。

### FR-AUTH-004 退出登录

- 退出登录由服务端根据当前登录态识别用户身份，无需请求体。
- 退出登录后服务端撤销当前 session。
- 前端清除本地 `session_token`、工作台内存态、会话列表、收藏列表、当前对话和模型选择状态。
- 退出登录后返回登录页 `/sign_in`。
- 退出登录后不得继续展示上一位用户的对话或收藏数据。

## 5. 页面状态

| 状态 | 展示要求 |
| --- | --- |
| 未输入 | 登录按钮不可用或点击后提示必填 |
| 注册中 | 展示加载状态，禁止重复提交 |
| 注册失败 | 展示错误原因，例如账号已存在或两次密码不一致 |
| 注册成功 | 建立登录态后跳转首页，或提示注册成功并回到登录 |
| 登录中 | 展示加载状态，禁止重复提交 |
| 登录失败 | 展示错误原因 |
| 登录成功 | 跳转首页 |
| 恢复登录态中 | 展示恢复中状态，不展示旧账号数据 |

## 6. 接口范围

| 接口 | 说明 |
| --- | --- |
| `POST /api/auth/sign_up` | 注册 |
| `POST /api/auth/sign_in` | 登录 |
| `POST /api/auth/sign_out` | 退出登录 |
| `GET /api/auth/session` | 会话恢复 |

详细请求、响应和错误码见 [technical/auth.md](../technical/auth.md)。
