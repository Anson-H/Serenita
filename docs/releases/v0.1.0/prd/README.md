## 3. 版本定位

v0.1.0 只聚焦患者端最小可用闭环：

- 用户可注册账号、登录并进入患者主工作台。
- 用户可在账号设置中修改用户名称和密码，并配置自己的模型服务、API key、模型列表和 `chat`、`title`、`vision_parse`、`compact` 默认模型用途。
- 用户可在首页与 AI 助手进行基础对话。
- 系统以会话索引库和会话级 JSONL 时间线持久化对话历史。
- 用户可收藏有价值的 AI 回答，并在收藏页查看、编辑标签和取消收藏。

本版本的叙事主线是：用户安全进入自己的工作台，完成必要账号和模型配置，再完成一次可追溯、可恢复、可收藏的首页问答。报告、生活和原始文件入口只承担框架占位，不扩展为正式业务能力。

## 4. 目标用户

- 需要快速咨询健康问题的患者
- 帮助家人记录和理解健康建议的患者家属

## 5. 全局信息架构

v0.1.0 采用患者主工作台框架，本期交付账号设置、模型配置、首页基础对话和我的收藏闭环。

本期涉及以下页面和入口：

- 登录页 `/sign_in`
- 注册页 `/sign_up`
- 患者主工作台 `/`
- 指定会话页 `/chat/{session_id}`：打开某个历史会话，复用患者主工作台外壳
- 首页工作区
- 报告场景：侧栏场景入口，占位展示，本期不交付报告结构化解析入库和报告列表正式能力
- 生活场景：侧栏场景入口，占位展示，本期不交付生活管理能力
- 我的收藏页 `/favorites`
- 原始文件：左侧辅助入口占位，本期不录入正式文件
- 账号设置页 `/setting`

左侧全局导航从上到下包含：

- 品牌区：只展示 `Serenita`
- 场景入口：`报告`、`生活`，点击后仍停留在 `/` 并切换当前占位场景
- 按钮：`开启新对话`
- 对话记录区：展示最近会话；每行右侧使用删除图标按钮
- 底部辅助入口：`原始文件` 排在 `我的收藏` 上方；`原始文件` 为占位入口，`我的收藏` 进入我的收藏页 `/favorites`
- 当前登录用户摘要：左下角账号按钮展示当前 `user_name` 和设置图标；点击后直接进入 `/setting`

左侧主工作栏在 `/`、`/favorites` 和 `/setting` 均保持存在，不因右侧主工作区切换改变布局或控件组成；账号设置从左下角账号按钮进入 `/setting` 页面，退出登录位于账号设置一级导航；我的收藏页 `/favorites` 是可直接访问的独立 URL 页面。

右侧主工作区从上到下包含：

- 工作区标题栏与当前视图内容区。
- 场景内容区：v0.1.0 正式交付首页对话；`报告`、`生活` 和 `原始文件` 只保留占位状态。
- 底部共享输入区：在首页、报告和生活场景中保持同一套视觉结构，但 v0.1.0 只有首页场景可发起真实对话请求；报告和生活场景当前通过占位标题、输入框 placeholder、禁用文本输入和隐藏附件入口表达未开放状态，提交动作在前端被阻止。

## 6. 跨模块约束

- 登录、账号设置、模型配置、上下文资源、对话和收藏数据必须绑定当前 `account`。
- 前端不得仅依赖本地 `account` 判断权限；所有需登录接口都由后端校验登录态与账号关系。
- API key 不得写入前端本地持久化存储；模型服务配置接口可明文返回当前账号已保存的 API key 以支持编辑。
- 退出登录后必须清除当前用户的内存态和页面态，不得继续展示上一位用户的会话或收藏数据。
- 时间字段统一使用 ISO 8601 字符串。
- 业务接口主动返回的失败应提供可读错误信息；由代码显式包装的错误需包含稳定错误码，框架级参数校验错误当前可沿用 FastAPI 默认 422 结构。

## 7. 技术选型

| 层级 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | React + Vite | 患者端单页工作台 |
| 后端 | FastAPI (Python) | 提供 RESTful API |
| 数据库 | SQLite | 本地文件存储，按账号隔离 |
| 部署形态 | 本地 API 或服务端 API | 开发阶段可本地运行，生产环境可部署为服务端 |
