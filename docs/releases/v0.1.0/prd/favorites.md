## 1. 目标

收藏模块负责把用户认为有价值的 AI 回答沉淀为快照，避免原会话变化或删除后丢失重要内容。

本模块交付：

- 助手回答收藏入口
- 收藏状态同步
- 我的收藏列表
- 收藏详情
- 收藏标签编辑
- 原回答单条取消收藏
- 批量取消收藏
- 返回原对话
- 原会话删除后的快照保留

本模块不交付：

- 收藏页独立加载失败重试状态
- 收藏页单条取消收藏入口
- 收藏分享
- 收藏导出
- 收藏搜索
- 收藏文件夹
- 收藏公开发布

## 2. 入口与页面结构

收藏有两个入口：

- 首页对话中每条助手回答底部的收藏按钮。
- 左侧全局导航中的 `我的收藏`，进入 `/favorites`。

`我的收藏` 页面路由为 `/favorites`，在同一患者主工作台外壳中展示当前用户收藏列表，左侧主工作栏保持存在。点击收藏项后展示收藏详情。

收藏页不依赖原会话仍然存在；原会话已删除时，收藏详情仍展示收藏时保存的快照。

## 3. 用户流程

1. 用户在 AI 回答上点击收藏入口。
2. 系统校验来源消息属于当前 `account`、当前会话且为助手消息。
3. 系统生成收藏快照，记录来源类型、来源会话 ID、来源消息 ID、标题、内容快照、标签和创建时间。
4. 收藏成功后，原回答显示已收藏状态。
5. 用户进入 `我的收藏` 查看收藏列表。
6. 用户点击收藏项，查看收藏详情。
7. 用户可通过标签胶囊新增或删除收藏标签，结束编辑时自动保存。
8. 用户可从收藏详情返回原对话；若原会话已删除，则不展示返回原对话入口。
9. 用户可在原回答上再次点击收藏按钮取消收藏，也可在收藏页批量取消收藏。
10. 取消收藏只删除收藏记录，不删除原始对话。

## 4. 功能需求

### FR-FAV-001 创建收藏

- 每条助手回答都应提供收藏入口。
- 未收藏状态点击后创建收藏快照。
- 收藏来源类型 v0.1.0 仅支持 `message`。
- 仅允许收藏助手消息，不允许收藏用户消息、思考过程或不存在的消息。
- 收藏记录必须保存足以定位原始消息的来源会话标识和来源消息标识。
- 同一 `account`、同一来源类型、同一来源会话和同一来源消息不得重复收藏。
- 收藏失败时展示明确反馈，且不影响原回答展示。

### FR-FAV-002 收藏状态同步

- 收藏成功后原回答展示已收藏状态。
- 已收藏状态再次点击会直接取消收藏。
- 切换会话、刷新收藏列表或重新进入工作台后，收藏状态应根据后端收藏列表恢复。

### FR-FAV-003 收藏列表

- `我的收藏` 页面展示当前用户的收藏列表。
- 列表项至少展示标题、来源类型、创建时间、内容摘要和标签。
- 列表项的阅读顺序为标题、内容摘要、元信息、标签；元信息至少包含来源类型和创建时间。
- 标签以胶囊控件展示，支持在列表内直接进入编辑状态、新增标签和删除单个标签。
- 无收藏时展示空状态文案：“还没有收藏，遇到重要回答可以先收藏起来。”
- 列表页支持单条查看详情。
- 列表页支持显式进入批量选择模式；进入后不自动选中收藏，用户可手动选择、全选、取消全选、批量设置标签或删除选中收藏。
- 收藏总数展示在列表末尾，不占用顶部工具栏主标题区域。

### FR-FAV-004 收藏详情

- 点击收藏项后展示收藏详情。
- 收藏详情展示收藏时的内容快照。
- 收藏详情标题下方展示来源类型、创建时间和标签。
- 收藏详情支持通过标签胶囊控件新增或删除标签；结束编辑或点击控件外部时自动保存，不展示独立保存按钮。
- 收藏详情可提供“返回原对话”入口。
- 原会话仍存在时，返回原对话使用 `source_session_id` 和 `source_id` 定位来源消息；当前前端跳转到 `/chat/{source_session_id}` 并高亮来源消息。
- 原会话已删除时，收藏详情仍展示快照，不展示返回原对话入口。
- 在窄屏宽度下，收藏列表保持单列，点击收藏项后收藏详情以覆盖式详情抽屉展示，并提供“返回收藏列表”入口。

### FR-FAV-005 取消收藏

- 用户可从原回答取消收藏；收藏页通过批量选择模式删除选中收藏。
- 用户可在收藏页批量取消收藏。
- 取消收藏不删除原始对话。
- 批量取消收藏时，已成功删除和失败项应可区分。
- 收藏取消失败时展示明确反馈。

### FR-FAV-006 数据隔离

- 收藏记录必须绑定当前 `account`。
- 当前 `account` 只能看到自己的收藏。
- 后端校验当前登录态与收藏记录的关系。
- 不同 `account` 之间不能互相看到收藏。

## 5. 页面状态

| 状态 | 展示要求 |
| --- | --- |
| 无收藏 | 展示空状态文案 |
| 有收藏 | 展示收藏列表 |
| 详情未选择 | 可只展示列表 |
| 详情已选择 | 展示快照、标签编辑和可用操作 |
| 批量选择中 | 展示已选状态、全选/取消全选、批量设置标签和删除选中收藏按钮 |
| 原会话不存在 | 展示快照，不展示返回原对话入口 |

## 6. 接口范围

| 接口 | 说明 |
| --- | --- |
| `GET /api/favorites` | 收藏列表 |
| `GET /api/favorites/{favorite_id}` | 收藏详情 |
| `POST /api/favorites` | 创建收藏 |
| `PATCH /api/favorites/{favorite_id}` | 编辑收藏标题或标签 |
| `DELETE /api/favorites/{favorite_id}` | 取消收藏 |
| `POST /api/favorites/batch-delete` | 批量取消收藏 |

详细请求、响应和错误码见 [technical/favorites.md](../technical/favorites.md)。
