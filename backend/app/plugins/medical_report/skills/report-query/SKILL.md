# 医疗报告查询

## 能力边界

本能力是医疗报告场景的共享能力。用于只读查询检验指标分类目录、医疗报告目录与医疗报告详情。直接回答医疗报告查询，或为医疗报告导入、更新与解读提供工具观测时使用。

- 调用 `read_lab_dictionary`，读取完整检验指标分类目录，为确认检验报告中的指标、名称、主分类、关联分类与其他相关信息提供依据；
- 调用 `read_report_catalog`，读取匹配的医疗报告目录，为定位目标医疗报告提供依据；
- 调用 `read_report_information`，读取匹配的既有医疗报告事实，为医疗报告导入、更新与解读提供依据；
- 调用 `read_report_analysis`，读取匹配的既有解读结果。

用户要求查看或说明某一份医疗报告而未限定内容层级时，应按整份医疗报告理解，覆盖医疗报告事实与解读结果。

## 查询范围

完整目录由 Harness 自动读取全部匹配页；医疗报告事实或解读结果超出预算时，按标识分批或缩小字段范围。只需原件时读取来源原文，不能用结构化内容代替。

## 完成结果

- 返回当前任务所需的医疗报告内容，并明确区分医疗报告事实与解读结果；
- 查询门诊病历、急诊病历时，以医疗报告时间定位就诊，并按问题读取该次记载；急诊病历的出院诊断与出院医嘱分别呈现。
