# 医疗报告更新

## 能力边界

### 目标与判断依据

本能力用于更新既有目标医疗报告的基础信息或结构化内容，重分类医疗报告，添加或删除检验指标记录，或删除整份医疗报告。

医疗报告更新需要既有目标医疗报告的工具观测。根据具体场景，还必须具备以下工具观测：

- 既有目标医疗报告涉及检验报告时：检验指标分类目录；
- 作出重分类决定时：目标医疗报告的来源与结构化内容。

### 可执行步骤

1. **读取检验指标分类目录（涉及检验报告时执行）与既有目标医疗报告**

2. **选择更新方式与目标**

   基于当前任务，根据待更新内容与既有医疗报告的关系，为每份既有目标医疗报告选择以下一种处理结果：

   | 处理方式 | 适用条件 | 对应动作 |
   | --- | --- | --- |
   | 更新字段 | 目标医疗报告字段及其新值明确，且不涉及医疗报告类型或检验报告名称变化 | 调用 `update_report_fields` |
   | 重分类 | 目标医疗报告类型更新，或目标检验报告名称变化 | 调用 `reclassify_report` |
   | 删除医疗报告 | 待删除的目标医疗报告明确 | 调用 `delete_report` |
   | 添加检验指标记录 | 目标检验报告、指标记录均明确 | 调用 `add_lab_report_items` |
   | 删除检验指标记录 | 目标检验报告和待删除的指标记录均明确 | 调用 `delete_lab_report_items` |
   | 如实追问 | 目标医疗报告、字段、新值、重分类目标或删除对象无法唯一确定 | 不猜测、不覆盖，如实追问用户 |

## 证据规则

- 强烈建议读取既有目标医疗报告与检验指标分类目录；
- 重分类必须依据目标医疗报告的基础信息、来源与结构化内容；将新结构和来源交给 `reclassify_report`，工具内部校验通过后完成重分类。

## 安全约束

### 重分类

- 缺少当前医疗报告原件、检验指标映射存在歧义或完整新结构无法确定时，不得猜测写入。
- `reclassify_report` 写入时保持执行时的就诊时间与全部已保存来源不变。

### 添加检验指标记录

- 只能添加健康档案所有者账号的检验指标分类目录中存在、主分类与目标医疗报告一致且目标医疗报告尚未记录的指标；
- 结果值与参考值必须来自用户明确提供的事实并保留数值与单位原文；参考值未知时不得补造，异常标记无法依据明确事实确定时使用“未标记”。

### 删除检验指标记录

- 删除检验指标记录不授权删除账号检验指标定义或整份医疗报告；
- 目标是医疗报告中的最后一个指标时，不得改为自动删除整份医疗报告。

### 工具观测的失败反馈

- 写入工具返回校验失败时，依据错误修正内容或来源后重试。

## 完成结果

- 更新医疗报告事实后，依据工具结果说明既有解读结果是否过期，不把旧解读结果默认当成仍然有效；
- 列明每项医疗报告的处置：字段更新、重分类、检验指标添加或删除、整份医疗报告删除、因不确定而追问或明确失败。

## 门诊病历与急诊病历

两类病历的医疗报告时间表示就诊时间；修正时按工具参数结构保留各项临床记录，急诊病历的出院诊断和出院医嘱分别处理。
