# 医疗报告解读规范

## 一、解读原则

1. 按临床重要性分配篇幅：关键异常和趋势完整解读，必须详细；次要正常结果、轻微变化及无关背景简要带过，不逐项展开，简洁为主。
2. 趋势比较写明具体日期、数值和单位，并确认检测项目及参考范围具有可比性。
3. 选取最重要的改善、稳定表现、持续问题、微小波动和异常风险进行解读。
4. 同日其他医疗报告可用于综合判断，并区分本医疗报告直接发现与跨医疗报告综合结论。
5. 以医疗报告中的指标、数值和异常标记准确有效为前提，首先从医学角度解释结果。
6. 仅在数值达到生理上极不合理的程度、与同日相关指标严重矛盾、短期复查出现数量级差异，提示复查确认。
7. 只陈述与本医疗报告核心判断直接相关且有病例资料支持的结论，不反驳未出现的推论。
8. 审核、更新或重写后的解读结果只呈现最终医学判断，不保留对原有解读的批改、反驳或纠错痕迹。不采用“不能证明A，也不能确认B”“不是A，而是B”“不宜将……解读为……”等围绕旧说法纠偏的表达。应直接写明当前最支持的原因、关键证据、临床意义及重新评估条件；例如“综合判断，本次变化最符合A，主要依据为……；若后续出现……，则重新评估B”。只有其他诊断已由病例提出且会改变风险或处理时，才说明其当前可能性。

## 二、指标解释

对重要异常指标、关键正常指标和明显趋势，按照以下顺序解释：

1. 指标主要反映的生理功能或临床问题。
2. 本次结果相对既往发生的具体变化。
3. 该变化在当前治疗阶段最可能代表的意义。
4. 相关指标是否形成相互支持或相互矛盾的组合。
5. 仅说明有本例资料直接支持且会改变当前判断的影响因素；无证据的理论因素不写。仅在会改变诊断、风险或处理时说明证据属性。

按照“指标含义—本次变化—组合判断—临床意义”组织内容。指标解释直接写入相应解读板块。

### 示例：

“ALT和AST主要反映肝细胞损伤，本次二者较前同步下降，结合胆红素和INR保持稳定，支持肝细胞损伤正在缓解；转氨酶恢复与肝组织整体修复程度仍需结合后续合成功能和影像变化判断。”

## 三、诊断与病因判断

仅对关键异常或尚有诊断分歧的问题说明最可能原因及关键证据。次要可能仅在会改变后续检查或处理时补充；轻微异常和已有明确解释的问题不展开鉴别。原因不明确时，直接说明异常程度、趋势和验证方法，不列举缺乏本例证据的假设，也不采用“提出可能原因后再说明没有证据”的结构。

各种可能按照概率从高到低排列，并采用与证据强度相匹配的表达：

- 明确诊断——“本医疗报告明确诊断为……”“现有证据可以确认……”
- 高度可能——“综合判断，高度考虑……”“现有表现最符合……”
- 中等可能——“目前首先考虑A，其次考虑B……”
- 把握有限——“现有资料暂时难以区分A和B，其中A相对更可能……”

发生时间、指标组合、已知机制和排除其他主要原因共同支持时，可以写“最可能由……引起”。只有时间关联时，写明“时间上与……相关，首先考虑其影响，后续趋势可进一步验证”。

多个因素共同参与时，区分主要因素和次要因素。后续结果改变证据权重时，及时调整原判断。

病理、特异性检查、适当时间窗内的高敏感度检查或多项相互印证的证据，可以支持“确认”“排除”或“基本排除”。单项非特异性结果仅赋予有限证据权重，优先正面说明当前最支持的判断；只有当某种诊断或病因已在现有资料中被提出并需要鉴别时，才说明其“目前不支持”或“可能性较低”。

## 四、预计恢复时间

仅对主要、可逆且趋势较明确的异常，给出一个恢复时间范围和一个重新评估条件；无法预测或临床意义较小的变化不写“后续预期”。

## 五、板块定义

- 好消息——本次新出现的明确改善、异常恢复或重要风险下降。
- 稳定信号——多次保持正常、重要功能稳定或既有问题保持平稳。
- 僵持点——经过至少两个可比时间点仍持续异常或停留在平台期。
- 微小波动——变化幅度较小、临床意义有限，更符合生理波动、日间变化或短期状态影响。
- 需注意信号——明显异常、连续恶化、具有潜在风险或可能影响近期治疗安全的发现；说明核心判断、风险程度和处理触发条件。
- 近期关注重点——说明下一步复查项目、观察症状，以及支持或修正当前判断的变化。
- 后续预期——给出条件式趋势、预计恢复时间及重新评估条件。

同一发现归入“好消息、稳定信号、僵持点、微小波动、需注意信号”中的一个板块。“近期关注重点”和“后续预期”用于补充观察方法及时间判断。

## 六、输出格式

批量输出时先写来源文件名或医疗报告标题，再按以下格式输出每份解读结果：

- 好消息——……
- 稳定信号——……
- 僵持点——……
- 微小波动——……
- 需注意信号——……
- 近期关注重点——……
- 后续预期——……

### 输出要求：

1. 板块按照固定顺序排列，只保留具有实质内容的板块。
2. 每个板块出现一次，并使用一个连续段落。
3. 每项发现选择一个主要板块，相关监测和时间预测分别放入“近期关注重点”及“后续预期”。
4. 每篇医疗报告优先解读最重要的1—3组发现。
5. 使用准确、克制且有明确判断的医学表达。
6. 治疗相关内容可以提出治疗方向、适用条件和风险权衡，并注明最终方案由主管医生结合整体情况确定。
7. 解读应直接、完整地表达当前证据支持的判断，描述当前发现及其意义。确有风险时，将具体监测项目和触发条件写入“近期关注重点”，不在其他板块附加笼统保留意见与保守性尾句。

## 七、叙事与语言风格

1. 在保留证据边界的前提下采用叙事性表达。每个板块先说最重要的当前结论，再自然串联本次发现、既往比较、指标组合、临床意义与后续验证条件，使读者能够连续跟随推理过程。
2. 推理按“核心结论—关键证据—与既往及相关指标的联系—当前治疗阶段的意义—改变判断的条件”展开。可使用“更关键的是”“结合……来看”“这表明”“因此”“但”“若后续……则……”等连接词明示逻辑关系，不将证据和结论写成互不衔接的短句清单。
3. 将影像、检验或病理术语直接翻译为本例中的临床意义，说清“这一发现意味着什么”以及“为什么支持当前判断”。避免只复述数值，也避免使用超出原始医疗报告和病例证据的形象化比喻。
4. 突出与当前治疗阶段的联系。在资料已有记录时，将本次结果与即将进行的治疗、治疗后的观察窗口和复查节点衔接起来，让解读结果呈现治疗过程中的动态判断，而非孤立的静态摘要。
5. 次要正常结果仅在支撑核心判断时写入，避免与结论无关的背景。

## 八、门诊病历与急诊病历

按原件中的主诉、现病史、检查、诊断和处理意见理解该次就诊。急诊病历还需关注抢救、留观、出院诊断与出院医嘱。说明与当前任务相关的重点，保留“待查”“不详”等原件表达，不把就诊时的初步判断改写为已经确诊，也不从未填写的字段推导阴性结果。原件中的处理意见与解读提出的建议应有清晰出处。

成员既往史取证范围按技能正文执行。没有数值或可比时间点时，不编造指标趋势。
