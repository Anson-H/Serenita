# 身体指标与饮食记录

## 能力边界

### 目标与判断依据

本能力用于查询和整理身体指标、饮食、睡眠与运动，保存用户提供或授权识别的记录，更新既有记录，以及管理饮食记录的图片关联。

当前身体指标工具不提供导入任务的创建、提交或批次删除。

遵循系统提示词的默认导入授权：用户提供当前成员实际的身体指标、餐食照片或饮食、睡眠、运动资料时，主动读取并保存对应记录及相关饮食图片，不要求额外发出保存命令或确认保存意愿。发生时间、实际摄入情况等事实结合上下文确定；影响执行的必要信息不足时再询问，允许未知或估算的内容按下文规则处理。纯知识咨询、示例、假设及明确不保存的资料不按实际记录写入。

日记中的饮食、运动、睡眠或测量明细也可以保存为身体指标记录；同一份明细允许同时保留在健康日记中。按用户目标和上下文确定保存范围，不能因创建身体指标记录而删除日记原有明细。需要同时维护日记时读取健康日记技能，分别确认保存结果；两处内容不自动同步。是否支持某项明细以身体指标分类目录为准，没有对应类型或必要信息不足时不能补造记录。

### 按当前任务选择行动

| 当前任务 | 所需依据 | 对应行动 |
| --- | --- | --- |
| 确定支持的指标、单位或记录类型 | 身体指标分类目录 | 调用 `read_body_metric_catalog`，按目录选择测量指标、餐次或睡眠阶段 |
| 查询某天、某类或某来源的记录 | 用户指定的范围与记录目录 | 调用 `read_body_record_catalog` 读取记录目录并定位目标；需要数值、备注、食物、睡眠阶段或图片关联时调用 `read_body_record` |
| 整理趋势、累计值、均值或覆盖情况 | 范围明确的统计工具观测 | 调用 `read_body_statistics`；需要完整趋势或原始点时继续读取对应序列 |
| 创建一条测量、饮食、睡眠或运动记录 | 用户授权、实际发生时间及该类型所需内容 | 调用 `create_body_record`，使用与记录类型一致的业务结构 |
| 更新已有数值、时间、餐次、食物或睡眠阶段 | 目标记录的完整工具观测与明确的新值 | 调用 `update_body_record`，只提交本次要更新的业务字段 |
| 删除一条记录 | 明确的删除授权与唯一目标 | 调用 `delete_body_record`，记录及其图片关联一并删除 |
| 为饮食记录保存图片 | 图片保存授权、目标饮食记录和当前会话图片 | 调用 `attach_body_record_file` |
| 解除饮食记录的一张图片关联 | 明确的解除关联授权和已读取的图片关联 | 调用 `detach_body_record_file`，保留饮食记录本身 |
| 目标、时间、必要数值或来源存在歧义 | 当前输入与工具观测仍不足以判断 | 如实追问，或在允许未知的字段保留未知 |

## 证据规则

- 涉及单条记录的具体判断、更新或食物及阶段明细时，读取记录内容；图片标识取自目标饮食记录的 `files`。
- 测量值、设备名称、测量方法与营养标签内容分别保留依据，照片估算另行标注。
- 食物识别或标签换算需要图片内容；当前会话无法读取某张已保存图片时，必要时请用户提供原图。
- 趋势变化先核对时间范围、单位、来源、设备和方法；需要健康背景时，按问题读取相关医疗资料。

## 查询与统计

### 范围和分页

按用户的问题确定日期范围、分类、来源及统计时区。日期筛选包含起止日期。来源筛选使用已读取记录或统计工具结果中的来源名称；不同来源的数据可分别比较。

记录目录由 Harness 自动读取全部匹配页，内部保存查询范围与分页位置。

`read_body_statistics` 的汇总覆盖全部匹配记录，序列中的 `preview` 仅是有界预览。需要完整趋势时，使用汇总工具结果中的 `series_id` 读取按日汇总 `buckets` 或原始点 `points`，由 Harness 保持筛选与视图自动读取全部序列页。统计序列的分页不缩小汇总范围；不能根据预览点数判断总记录数。

判断覆盖情况时检查总记录数、覆盖起止时间、有记录日期、缺失值数量及过期评分排除数量。区间记录可能跨越所选日期，原始点保留完整原始区间；按日值中的分摊含义以工具观测为准。未记录的日期和未知值不当作零，部分覆盖不能描述为完整连续监测。

### 统计口径

- 序列按指标、来源、设备、测量方法、单位及睡眠评分满分分别形成。不能合计可能重叠的来源或设备的步数、能量和时长，也不能混合 SDNN 与 RMSSD、身体成分的比例、质量、等级和面积。
- 测量采用分类目录规定的统计方式。回答中区分最近值、原始记录均值、范围、累计值和有记录日均，不把它们互相替换；没有记录的日期不进入有记录日均的分母。
- 同源累计统计优先使用日汇总；没有日汇总时按不重叠区间统计。检查 `omitted_overlaps`，有被排除的重叠记录时说明其对结果的影响，不把原始点再次相加后覆盖工具给出的累计值。
- 跨日累计测量按实际区间时长分摊到各自然日。`allocated_intervals` 表示存在这种分摊；将分摊说明为日内分布估算，不能描述为各时刻的实际采样。只有日汇总时不能虚构分钟级变化。
- 睡眠归属醒来日期，运动归属开始日期。睡眠时长提供期间累计和有记录日均，过期睡眠评分退出有效评分统计；解释评分时同时交代量表、来源与过期状态。
- 运动能量与活动能量分别保存，运动时长与锻炼时长分别统计，不能把可能重叠的内容合计。当前运动统计序列提供运动时长；需要运动距离或运动能量时读取相应记录明细，并说明实际读取范围和计算依据。

## 记录事实与时间

### 共同要求

测量使用实际发生日期时间；睡眠和运动使用实际起止日期时间。区间记录与日汇总保留开始、结束及精度。日期时间带时区偏移，并使用与来源或当前任务一致的 IANA 时区。缺少会影响保存的日期时间时询问用户。

数值与单位一起理解和保存。测量指标与单位按身体指标分类目录和工具参数结构填写；饮食及运动能量用 kcal，碳水化合物、蛋白质与脂肪用 g，运动距离用 km，睡眠及运动时长用分钟。必要换算说明原单位和依据；来源单位不明或不受支持时，根据真实错误核实，不能只替换单位文字。

来源名称、设备、输入来源类型和外部标识忠于实际输入。外部稳定标识仅在来源已提供时使用；手工修正不改变记录标识或来源身份。图片识别记录标明图片识别来源，估算部分另行说明。

### 测量

- 血压的收缩压与舒张压必须来自同一次测量并保存在同一条记录中；同次脉搏已知时可附带。缺少其中一个血压值时询问，不能拼接不同时间的测量。
- 血糖保留已知的空腹、餐后等测量背景。HRV 保留 SDNN、RMSSD 或未知方法，不能从设备名称猜测算法。
- 皮下脂肪与内脏脂肪保留来源实际使用的单位，不能把等级当作百分比或质量。不同口径可分别呈现，不能直接推断数值增减。
- 夜间心率需要来源明确标注或有实际读取的睡眠区间与测量依据，不能按固定时钟时段替代睡眠，也不能把普通心率自动改为夜间心率或静息心率。

### 饮食与图片识别

每次进食独立记录，一餐可有多次进食。餐次使用早餐、早加餐、午餐、午加餐、晚餐、晚加餐；依据用户表述或已确认信息填写，无法确定时询问或保留未分类，不能只按照片内容猜测餐次。

识别食物或营养标签时，区分图片展示的份量与实际摄入份量。营养标签优先使用可辨认的数值，明确每份或每 100 克等计量依据，再根据实际摄入量换算；标签上整包的值不能直接当作用户已摄入量。只有标签而摄入量未知时，可说明单位份量的营养信息，实际摄入数值保持未知或追问。

食物照片中的份量、配料、油和酱料存在不确定性。能够给出合理估算时，将 `estimated` 设为真，并在 `basis` 说明食物判断、份量假设及营养估算依据；不能把估算描述为精确测量。食物或摄入量无法判断时，询问用户或保留未知。营养标签、用户提供数值与照片估算分别保留依据。

单次进食含多个食物时使用 `foods`，每项营养值代表该项实际摄入份量。添加食物时使用父记录内唯一的稳定标识，更新沿用已读取的标识。有明细时整餐营养总量由服务端计算，某项食物的某种营养值未知时，该种整餐总量也为未知，不能按零补齐或重复累加整餐与明细。

需要保存图片时，将当前会话图片关联到已存在的目标饮食记录。图片关联仅适用于饮食记录；关联失败不代表已成功创建的饮食记录也失败。

### 睡眠与运动

睡眠阶段必须来自已读取数据，每段位于主睡眠区间内，起止时间有效且互不重叠；保留来源原有阶段名称。不能从总时长推测浅睡、深睡或快速眼动时长，也不能从睡眠区间推断整段都在睡眠。

有睡眠阶段时，服务端从阶段计算实际睡眠时长，排除清醒与卧床；没有阶段时可保存来源已提供的睡眠时长，并说明阶段缺失。睡眠评分必须有来源依据和量表满分，不能根据时长自行编造评分。

运动记录保留运动名称、起止时间和实际运动时长；距离与能量未知时保持未知。实际睡眠或运动时长不能超过起止区间，不把暂停、卧床或未说明用途的时间自动计入实际时长。

## 修正、删除与图片关联

更新前读取目标记录，确定类型、已有值及用户要求的变更。`update_body_record` 合并提交的业务字段，省略字段保持原值；记录类型与来源身份不通过该工具更新。目标类型不符或用户实际要求更换来源时，先说明现有能力和目标差异，不能擅自删除再创建。

`foods` 和 `stages` 一旦提交就整组替换。更新其中一项时保留未要求删除的全部明细和稳定标识，不能只提交被更新的一项。更新食物份量时，根据已有营养依据判断能否按比例换算，同步提供有依据的新营养值；局部更新工具不会仅凭份量变化自动换算营养，未知项保持未知。

更新睡眠起止时间或阶段时，同时检查全部阶段的边界与重叠情况。已有评分是否过期由服务端维护；区间、阶段或时长发生有效变化后，依据工具结果说明评分状态，不能自动生成新评分或擅自宣布原评分仍有效。仅更新备注不改变评分依据。

删除一条记录会同时删除其图片关联；只移除图片时调用解除关联工具，保留饮食记录。已删除的来源记录不会因重新导入自动恢复，不能把重导当作撤销删除。

导入管理的记录发生有效业务更新或实际图片关联变化后，会成为独立记录，之后删除原导入批次也会保留它；用户的任务涉及批次归属时，按工具结果解释这一影响。未发生实际变化的提交不能描述为已改变内容。

## 完成结果

- 查询或趋势整理交代覆盖日期、来源、单位、统计口径及统计覆盖信息，说明会影响比较的缺失和估算。
- 维护结果说明记录内容与图片关联各自的变化；保存或更新后提供可编辑记录链接，便于用户继续编辑时间、份量、餐次和数值。
- 涉及照片估算、未知营养值、睡眠阶段缺失或评分过期时，交代相应依据及其影响。
