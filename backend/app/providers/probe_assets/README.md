# Capability probe assets

These files are deterministic, synthetic inputs used only for provider capability probes:

- `image.png`: 32 × 32 RGB image.
- `document.pdf`: one-page PDF containing the text `PDF`.
- `audio.wav`: one-second, 16 kHz mono tone.
- `video.mp4`: three-second MP4 clip.

They contain no user or patient data. Keep each sample small, valid, and directly inspectable.
